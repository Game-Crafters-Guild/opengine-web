@openengine/web examples

A WebGPU renderer and an entity-component world behind a small JavaScript API. Each example is one page: its engine calls in main.js, its controls in a script beside it. They need a browser with WebGPU: current Chrome or Edge.

  • Model viewer: pick a sample model or open your own .glb, orbit it, set the time of day, stop or start the turntable, and show the frame rate. 53 lines of engine calls in main.js; 264 lines of page and panel. Models: Khronos glTF Sample Assets, CC0 1.0. Early access (alpha).

Every asset's source and license is listed in ASSET_PROVENANCE.md. The pages load coi-serviceworker.js (MIT) to run the threaded build on hosts that cannot send isolation headers.
